Welcome to Mewndo

Mewndo keeps a copy of every version of every file in the folders you choose, and all of it stays on this computer. If an AI agent deletes or changes something it shouldn't, you can put the whole folder, or just some files, back the way they were.

    Folders larger than 20 GB, or that contain Mewndo's own data, can't be protected.

            Add Mewndo to Claude Code?

            Claude Code will run Mewndo's save point script when a session starts, and ask Mewndo before every command, file edit or file read (Guard). Mewndo answers allow, deny or ask, with a reason Claude reads: it refuses secrets (.env files, keys), changes outside the folder, and deletes your brief didn't name, and asks you before recursive deletes, hard resets and force-pushes. Deletes it allows get a save point first.

            What it can't do: while Mewndo isn't running, Claude Code isn't checked and goes ahead as usual. The address includes a private token so only Claude Code on this computer can ask.

            Before every shell command, file edit and tool call, will run Mewndo's guard script, which asks Mewndo and answers allow, deny or ask with a reason the agent reads. It refuses secrets, changes outside the folder and deletes your brief didn't name, and stops recursive deletes, hard resets and force-pushes until you confirm.

            What it can't do: while Mewndo isn't running, the script lets harmless actions through and refuses deletes and other destructive commands. Codex can't pause to ask you, so "ask" reaches it as a refusal telling it to ask you. Codex's hosted tools (such as web search) don't go through hooks.
