What it can't do

    Habits

    Learned rules

    When you give an agent the same answer three times in a project, Mewndo offers a Habit card: "Always allow this?" Yes writes a rule into your rules file, and the agent isn't asked about that command again.

    What it can't do: Mewndo reads the rules file when it starts, so a removed rule stops applying the next time Mewndo starts. A rule applies in every project, not only the one it was learned in. "Never ask" answers aren't written to the file, so they're forgotten when Mewndo restarts and aren't listed. Rules you wrote yourself aren't listed here: edit the file for those.

    Notifications

    Do not disturb

    While it's on, cards still arrive in the Inbox and on the dock's badge, but none pops up beside the dock and Mewndo shows no Windows notifications. Permission requests from your own agents still show: the agent is waiting for you.

    What it can't do: this is Mewndo's own setting. It doesn't read or change Windows' Do not disturb, and warnings still show inside Mewndo's window.

    Sound

    Off unless you turn it on. Cards never take focus, and during Do not disturb only a permission request makes the sound. The sound plays through Mewndo's window, so it follows Windows' volume for Mewndo.

    Account

    Invite code and cloud

    Offline. The app doesn't connect to a Mewndo account yet; everything stays on this computer.
